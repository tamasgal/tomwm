include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--selected [no]:: Filter the tags currently shown on the monitor
--occupied [no]:: Filter the tags that hold at least one window
--format <output-format>:: Specify the output format
--count:: Print the number of tags instead of the tags themselves
--json:: Print the result in JSON format
