// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`<n>` is relative when it carries an explicit sign and absolute otherwise, so `nmaster +1` adds a
window to the master area and `nmaster 2` sets it to exactly two. The value never goes below zero;
with zero, every window goes into the stack area and takes the full width.
