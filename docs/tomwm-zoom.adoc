// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The master area holds the window that needs attention right now. `zoom` moves the focused window to
the front of the stack, which puts it in the master area.

If the focused window is already the master, it swaps places with the next tiled window instead, so
pressing the binding twice returns you to where you were. This is dwm's `zoom`.

The command does nothing when the layout is `floating`, or when the focused window is floating.
