// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
tomwm focus [-h|--help] [--ignore-floating] [--boundaries <boundary>] [--fail-if-noop] (left|down|up|right|next|prev|master)
tomwm focus [-h|--help] --window-id <window-id>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`next` and `prev` walk the stack, which is the order the tiling layouts use, wrapping around at the
ends. This is dwm's `focusstack`.

`left`, `down`, `up` and `right` pick the nearest visible window in that direction instead, which
is often what you want when the stack order is not what you are picturing.

`master` focuses the master window. On the master it goes back to the most recently focused tiled
window, so the binding switches between the master and wherever you were in the stack.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--ignore-floating:: Skip floating windows
--boundaries <boundary>:: Where directional focus may look. `monitor` or `all-monitors`.
                          The default is `all-monitors`
--fail-if-noop:: Exit with a non-zero code if the focus does not move
