== Synopsis

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`<fraction>` is relative when it carries an explicit sign and absolute otherwise, so `mfact +0.05`
widens the master area and `mfact 0.55` sets it to 55% of the screen. The value is clamped to the
range 0.05 to 0.95.
