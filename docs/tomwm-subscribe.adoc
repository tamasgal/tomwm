= tomwm-subscribe(1)
include::util/man-attributes.adoc[]
// tag::purpose[]
:manpurpose: Subscribe to TomWM events and receive notifications via socket
// end::purpose[]
:manname: tomwm-subscribe

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
tomwm subscribe [-h|--help] [--all] [--no-send-initial] [<event>...]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

This command connects to the TomWM server and receives real-time event notifications as JSON lines.
The connection remains open until terminated (e.g., via Ctrl+C).

On connect, the current state is sent immediately (focus-changed with the current window and tags, mode-changed with the current mode, etc.).

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help

--all:: Subscribe to all event types

--no-send-initial:: Do not send the initial state on connect

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

The following events can be subscribed to:

focus-changed:: Fired when window focus changes. Includes `windowId`, `tags`.

focused-monitor-changed:: Fired when the focused monitor changes. Includes `tags`, `monitorId`.

tags-changed:: Fired when the selected tags change. Includes `tags`, `prevTags`.

mode-changed:: Fired when the binding mode changes. Includes `mode`.

window-detected:: Fired when a new window is detected. Includes `windowId`, `tags`, `appBundleId`, `appName`.

binding-triggered:: Fired when a keyboard binding is triggered. Includes `binding`, `mode`.

// =========================================================== Output Format
include::util/conditional-output-format-header.adoc[]

Events are output as JSON lines (one JSON object per line):

----
{"_event":"focused-monitor-changed","monitorId":1,"tags":["dev"]}
{"_event":"tags-changed","prevTags":["base"],"tags":["dev"]}
{"_event":"mode-changed","mode":"main"}
{"_event":"focus-changed","windowId":28218,"tags":["dev"]}
----

// end::body[]
