= tomwm-move-to-monitor(1)
include::util/man-attributes.adoc[]
:manname: tomwm-move-to-monitor
// tag::purpose[]
:manpurpose: Move the focused window to another monitor
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
tomwm move-to-monitor [-h|--help] [--window-id <window-id>] [--focus-follows-window]
                               [--wrap-around] (left|down|up|right|next|prev)
tomwm move-to-monitor [-h|--help] [--window-id <window-id>] [--focus-follows-window]
                               [--fail-if-noop] [--] <monitor-pattern>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--wrap-around:: Make it possible to wrap around the movement

--focus-follows-window::
Make sure that the window in question receives focus after moving.
This flag is a shortcut for manually running `tomwm-focus` after a successful `move-to-monitor`.

--fail-if-noop::
Exit with non-zero code if moving window to monitor it already belongs to

--window-id <window-id>::
include::./util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right)::
Move window to monitor in direction relative to the focused monitor

(next|prev)::
Move window to next|prev monitor in order they appear in tray icon

<monitor-pattern>...::
Find the first matching monitor and move the window there.
Multiple monitor patterns is useful for different monitor configurations.
Monitor patterns are a 1-based index, `main`, `secondary`, `built-in`, or a case insensitive regex matched against the monitor name

// end::body[]
