// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

A floating window keeps whatever position and size you give it and is ignored by the tiling
layouts.

Dialogs are always managed floating and cannot be tiled, so the command fails on them. Which
windows count as dialogs is decided by an Accessibility heuristic; see
xref:tomwm-debug-windows.adoc[tomwm-debug-windows(1)] if you disagree with its verdict for some
application.
