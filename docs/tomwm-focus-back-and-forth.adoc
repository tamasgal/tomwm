// =========================================================== Description
== Description

// tag::body[]
{manpurpose}.
The element is either a window or a monitor showing no windows.

TomWM stores only one previously focused window in history,
which means that if you close the previous window,
`focus-back-and-forth` has no window to switch focus to.
In that case, the command will exit with non-zero exit code.

That's why it may be preferred to combine `focus-back-and-forth` with `view --back-and-forth`: +
----
tomwm focus-back-and-forth || tomwm view --back-and-forth
----

Also see: <<view, view>>
// end::body[]
